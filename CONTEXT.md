# Skill Catalog

This is a personal working catalog of reusable skills, some also offered to downstream users. Personal day-to-day usefulness takes priority when choosing which skills to maintain.

## Language

**Public Skill**:
A skill intended for downstream discovery and installation. Its value can extend beyond the maintainer's current personal use.

**Internal Skill**:
A skill maintained for this repository's own work rather than offered as part of its public catalog.

**Runtime Copy**:
A local copy of a skill used during execution. Multiple copies of the same skill do not constitute separate capabilities.

**Retirement Candidate**:
A skill being evaluated for removal from the maintained offering. Candidate status does not mean retirement or deletion has been approved.

**Retired Skill**:
A previously maintained skill deliberately removed from the current offering. Historical copies kept for recovery are not part of the active catalog.
