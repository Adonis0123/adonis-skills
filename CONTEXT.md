# Skill Catalog

This is a personal working catalog of reusable skills, some also offered to downstream users. Personal day-to-day usefulness takes priority when choosing which skills to maintain.

## Language

**Public Skill**:
A skill intended for downstream discovery and installation. Its value can extend beyond the maintainer's current personal use.

**Internal Skill**:
A skill maintained for this repository's own work rather than offered as part of its public catalog.

**Runtime Copy**:
A local copy of a skill used during execution. Multiple copies of the same skill do not constitute separate capabilities.

**Retirement Candidate**:
A skill being evaluated for removal from the maintained offering. Candidate status does not mean retirement or deletion has been approved.

**Retired Skill**:
A previously maintained skill deliberately removed from the current offering. Historical copies kept for recovery are not part of the active catalog.

**Catalog Site**:
The public website where visitors discover, evaluate, and install Public Skills. It presents the catalog; it does not decide which skills are maintained.
_Avoid_: web app, homepage

**Visitor**:
A person using the Catalog Site to find, judge, or install a skill. When the site's presentation serves the maintainer and a Visitor differently, the Visitor's ability to find and install wins.
_Avoid_: user (ambiguous with someone running a skill)

**Host**:
An agent product that installs and runs skills, such as Claude Code, Codex, Cursor, or Hermes Agent. Each Host has its own install method; the skill itself is the same.
_Avoid_: platform, client, IDE

**Scenario Group**:
A set of Public Skills shown together on the Catalog Site because a Visitor reaches for them in the same kind of work, such as Git delivery or code review. A skill belongs to one Scenario Group; its tags may still cross groups.
_Avoid_: category, section

**Featured Skill**:
A Public Skill the maintainer picks to show first on the Catalog Site. Featuring changes prominence only, not maintenance status.

**Display Name**:
The human-readable name a Visitor sees for a skill. The skill's slug stays the install identifier and appears beside the Display Name.
_Avoid_: title, label
