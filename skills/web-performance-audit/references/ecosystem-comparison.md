# Nearby skill comparison

This comparison explains why this skill exists. Recheck upstream sources before relying on exact commands because client and tool interfaces change.

| Nearby skill                                                                                                                          | Strongest use                                                                 | Gap this skill fills                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [Cloudflare Web Performance](https://github.com/cloudflare/skills/blob/main/skills/web-perf/SKILL.md)                                 | Core Web Vitals, Lighthouse, load/network diagnostics, field-vs-lab reasoning | Not an exhaustive authenticated multi-state application audit or Recorder/React instrumentation isolation loop                           |
| [Addy Osmani Web Quality Audit](https://github.com/addyosmani/web-quality-skills/blob/main/skills/web-quality-audit/SKILL.md)         | Broad performance, accessibility, SEO, and best-practice quality review       | Broader quality scope; less emphasis on every interactive tab, long-lived state, restoration, and evidence-led optimization backlog      |
| [Chrome DevTools MCP official skill](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/skills/chrome-devtools/SKILL.md) | Connect/select/snapshot workflows and reliable use of the DevTools MCP server | Tool operation, not an end-to-end product audit contract spanning Recorder, Computer Use, React-localization, and missing-tool fallbacks |
| [React Performance](https://skills.sh/affaan-m/ecc/react-performance)                                                                 | React render and code-level performance guidance                              | Framework-local guidance does not prove browser, media, network, memory, or user-impact causality                                        |

The combination in this skill is intentionally narrower than a universal web-quality checklist and broader than one profiling tool: exact authenticated journeys, exhaustive surface coverage, clean/instrumented controls, metric semantics, security preflight, recommendations with retests and stop conditions, and final state restoration.
