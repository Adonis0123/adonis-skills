## Components

| Name                                            | Kind               | Responsibility                                                                                                                                                                              | Code path                                                                                               |
| ----------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Maintainer                                      | external role      | writes skills, commits and pushes to `main`.                                                                                                                                                | `CONTEXT.md`                                                                                            |
| Private source export                           | external process   | overwrites the managed skills in this repo from the private source by allowlist, and leaves the source revisions and a sha256 list of the files; the export script is not in this repo.     | `.export-manifest.json`                                                                                 |
| `pnpm skills:new`                               | script             | scaffolds a skill with the internal skill `repo-skill-creator`, then runs quick-validate, `skills:validate` and `skills:index` in turn.                                                     | `scripts/create-skill.ts`, `.agents/skills/repo-skill-creator/scripts/`                                 |
| `SKILL.md`                                      | skill source file  | the entry of each public skill: frontmatter requires `name` (equal to the folder name), `description` and `metadata.author`; the body is the instructions for the agent.                    | `skills/<slug>/SKILL.md`                                                                                |
| `scripts/`, `references/`, `assets/`, `agents/` | skill source files | the scripts, per-scenario reference docs, template assets and `openai.yaml` a skill carries when it needs them; test files sit inside `scripts/`, with no separate `tests/` folder.         | `skills/<slug>/scripts/`, `skills/<slug>/references/`, `skills/<slug>/assets/`, `skills/<slug>/agents/` |
| `evals/`                                        | skill source files | a skill's behaviour cases and trigger cases.                                                                                                                                                | `skills/<slug>/evals/evals.json`, `skills/<slug>/evals/trigger-eval.json`                               |
| Skill groups                                    | data convention    | 34 public skills in 7 Scenario Groups: delegate, review, git, tools, frontend, docs, create.                                                                                                | `apps/web/content/skill-catalog.yaml`                                                                   |
| `skill-catalog.yaml`                            | config file        | holds the site's group order, the featured skills and each skill's bilingual display copy.                                                                                                  | `apps/web/content/skill-catalog.yaml`                                                                   |
| `skill-schema.ts`                               | library            | defines the zod schemas of the index and catalog and `findCatalogIssues`, shared by the validate and index scripts.                                                                         | `apps/web/src/lib/skill-schema.ts`                                                                      |
| `skills:validate`                               | script             | checks every skill's frontmatter rules and that its catalog entry is complete; writes no files.                                                                                             | `scripts/validate-skills.mjs`                                                                           |
| `skills:index`                                  | script             | parses every `SKILL.md`, the optional `showcase.yaml`, the catalog and git commit times, and generates the site index.                                                                      | `scripts/generate-skills-index.mjs`                                                                     |
| Generated index                                 | generated files    | the site pages' skill data: three JSON files for the list, the details and the group layout; never edited by hand.                                                                          | `apps/web/src/generated/`                                                                               |
| Catalog Site                                    | web app            | Next.js site with the home page, skill list and skill details (en/zh), plus `/llms.txt`, `/api/skills.json` and `/skills/<slug>.md`.                                                        | `apps/web/src/app/`, `apps/web/src/lib/skills.ts`                                                       |
| Host install config                             | config module      | defines the install commands of the three Hosts; the pages, `/llms.txt` and the JSON API all read it.                                                                                       | `apps/web/src/config/hosts.ts`                                                                          |
| `@adonis-skills/i18n`                           | workspace package  | gives the site the locale list and the Lingui config.                                                                                                                                       | `packages/i18n/src/`                                                                                    |
| `pnpm brand:sync`                               | script             | copies a design token snapshot from the brand repo `BRAND_REPO` points to, and generates the site's CSS variables and the root `DESIGN.md`; `brand:check` only compares and writes nothing. | `scripts/sync-brand-tokens.mjs`, `apps/web/src/styles/brand/`                                           |
| pre-commit hook                                 | quality gate       | when a commit touches skills, the catalog or illustrations, runs validation and indexing and requires the generated index to be staged; also runs prettier and typecheck.                   | `package.json` (`simple-git-hooks`), `scripts/precommit-skills.mjs`                                     |
| CI `quality`                                    | quality gate       | on PRs and pushes to `main`, runs validation, index freshness, brand and design token checks, site unit tests, script tests, i18n compile, lint, typecheck and build.                       | `.github/workflows/ci.yml`                                                                              |
| `privacy-scan`                                  | quality gate       | on every push and PR, scans for secrets, local paths, hostnames and loopback ports with gitleaks.                                                                                           | `.github/workflows/privacy-scan.yml`, `.gitleaks.toml`                                                  |
| `skills:eval-grade`                             | script             | grades collected run outputs against the expected Route in `evals.json`.                                                                                                                    | `scripts/grade-skill-evals.mjs`                                                                         |
| Plugin eval suite builder                       | script             | turns `agent-dispatch`'s `evals.json` into a case folder for `claude plugin eval`.                                                                                                          | `skills/agent-dispatch/evals/build_plugin_eval.py`, `evals/`                                            |
| `skills:install:local`                          | script             | installs the public skills into an in-repo mirror folder for local runtime tests; with `--sync-llm` makes sure the `.claude/skills` symlink points to it.                                   | `scripts/install-local-skills.ts`, `.agents/skills/`                                                    |
| Internal skills                                 | skill source files | skills that only serve this repo's development; not indexed, not published.                                                                                                                 | `.agents/skills/`                                                                                       |
| `marketplace.json`                              | config file        | declares the whole repo as one Claude Code plugin whose skill folder is `./skills/`.                                                                                                        | `.claude-plugin/marketplace.json`                                                                       |
| GitHub `main`                                   | external service   | the publishing surface: the three install methods and the site's source links all point to this branch.                                                                                     | `llms.txt`, `apps/web/src/lib/skills.ts`                                                                |
| Hosts                                           | external role      | the agent products that install and run skills: the `skills` CLI family (Codex, Cursor and others), Claude Code, Hermes Agent.                                                              | `CONTEXT.md`, `apps/web/src/config/hosts.ts`                                                            |
| Visitor                                         | external role      | finds skills on the site, judges whether one fits, and copies the install command.                                                                                                          | `CONTEXT.md`                                                                                            |

## Relations

| From                      | To                                              | Action                                                                                                                                | Protocol or data                                             |
| ------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Maintainer                | `pnpm skills:new`                               | runs the scaffold command                                                                                                             | CLI arguments or interactive input                           |
| `pnpm skills:new`         | `SKILL.md`                                      | creates the skill folder and rewrites `description`                                                                                   | file write                                                   |
| `pnpm skills:new`         | `skills:validate`                               | starts validation after scaffolding                                                                                                   | `pnpm` child process                                         |
| `pnpm skills:new`         | `skills:index`                                  | starts index generation after validation passes                                                                                       | `pnpm` child process                                         |
| Private source export     | `SKILL.md`                                      | overwrites every file of the managed skills                                                                                           | file write, listed in `.export-manifest.json`                |
| `skills:validate`         | `SKILL.md`                                      | reads and checks the frontmatter                                                                                                      | file read, YAML                                              |
| `skills:validate`         | `skill-catalog.yaml`                            | reads it and checks that every skill has an entry and its illustration exists                                                         | file read, YAML                                              |
| `skills:validate`         | `skill-schema.ts`                               | imports `findCatalogIssues`                                                                                                           | ES module import                                             |
| `skills:index`            | `SKILL.md`                                      | reads the frontmatter and splits the body into sections                                                                               | file read, Markdown                                          |
| `skills:index`            | `skill-catalog.yaml`                            | reads groups, featured skills and display copy                                                                                        | file read, YAML                                              |
| `skills:index`            | Generated index                                 | writes the three JSON files                                                                                                           | file write, JSON                                             |
| Catalog Site              | Generated index                                 | imports the skill list, details and layout at build time                                                                              | JSON import                                                  |
| Catalog Site              | `SKILL.md`                                      | reads the original text at build time and serves `/skills/<slug>.md`                                                                  | file read, `text/markdown`                                   |
| Catalog Site              | Host install config                             | reads each Host's install commands and renders them                                                                                   | TypeScript import                                            |
| Catalog Site              | `@adonis-skills/i18n`                           | reads the locale list and the Lingui config                                                                                           | workspace dependency                                         |
| `pnpm brand:sync`         | Catalog Site                                    | generates `brand-tokens.css`, `theme-roles.css` and `DESIGN.md`                                                                       | file write, CSS and Markdown                                 |
| pre-commit hook           | `skills:validate`                               | starts validation before a commit and blocks the commit on failure                                                                    | `pnpm` child process                                         |
| pre-commit hook           | `skills:index`                                  | regenerates the index before a commit and blocks the commit on unstaged differences                                                   | `pnpm` child process, `git diff`                             |
| CI `quality`              | `skills:validate`                               | runs validation on the runner                                                                                                         | GitHub Actions step                                          |
| CI `quality`              | `skills:index`                                  | regenerates the index and requires it to match what is committed                                                                      | GitHub Actions step, `git diff --exit-code`                  |
| CI `quality`              | `pnpm brand:sync`                               | checks in `--check` mode that the generated CSS matches the snapshot                                                                  | GitHub Actions step                                          |
| CI `quality`              | `scripts/`, `references/`, `assets/`, `agents/` | runs the skill publicity and script cases listed in `test:scripts`                                                                    | `node --test`                                                |
| CI `quality`              | Catalog Site                                    | runs unit tests, i18n compile, lint, typecheck and build                                                                              | `pnpm`, `turbo`                                              |
| `privacy-scan`            | GitHub `main`                                   | scans the full history of pushes and PRs                                                                                              | gitleaks, rules in `.gitleaks.toml`                          |
| `skills:eval-grade`       | `evals/`                                        | reads the expected Route and compares it with the outputs                                                                             | file read, JSON                                              |
| Plugin eval suite builder | `evals/`                                        | reads `evals.json` and generates the case folder                                                                                      | file read and write                                          |
| `skills:install:local`    | `SKILL.md`                                      | installs the skills into the mirror folder through `npx skills add ./skills`, then copies whole folders to restore filtered-out files | child process and file copy                                  |
| `skills:install:local`    | Internal skills                                 | writes the public skills' runtime copies into the same folder                                                                         | file write                                                   |
| Maintainer                | GitHub `main`                                   | pushes commits, which is the release                                                                                                  | `git push`                                                   |
| Visitor                   | Catalog Site                                    | browses and searches skills and copies install commands                                                                               | HTTPS                                                        |
| Visitor                   | Hosts                                           | runs the copied install command in a Host                                                                                             | the Host's own CLI or slash command                          |
| Hosts                     | GitHub `main`                                   | fetches `skills/<slug>/` or the whole repo                                                                                            | `npx skills add`, `/plugin marketplace add`, `hermes skills` |
| Hosts                     | `marketplace.json`                              | Claude Code reads the plugin manifest to find the skill folder                                                                        | JSON                                                         |
| Hosts                     | `SKILL.md`                                      | loads the skill's instructions at run time, then reads `scripts/` and `references/` as needed                                         | file read                                                    |
