## 组件

| 名称                                            | 类型         | 职责                                                                                                                         | 代码路径                                                                                                |
| ----------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Maintainer                                      | 外部角色     | 写技能、提交并推送到 `main`。                                                                                                | `CONTEXT.md`                                                                                            |
| 私有源导出                                      | 外部流程     | 把私有源里的受管技能按 allowlist 覆盖写入本仓，并留下来源 revision 与文件 sha256 清单；导出脚本不在本仓。                    | `.export-manifest.json`                                                                                 |
| `pnpm skills:new`                               | 脚本         | 用内部技能 `repo-skill-creator` 生成技能脚手架，再依次跑 quick-validate、`skills:validate`、`skills:index`。                 | `scripts/create-skill.ts`、`.agents/skills/repo-skill-creator/scripts/`                                 |
| `SKILL.md`                                      | 技能源文件   | 每个公开技能的入口：frontmatter 必填 `name`（等于目录名）、`description`、`metadata.author`，正文是给 agent 的指令。         | `skills/<slug>/SKILL.md`                                                                                |
| `scripts/`、`references/`、`assets/`、`agents/` | 技能源文件   | 技能按需带的脚本、分场景参考文档、模板资源和 `openai.yaml`；测试文件放在 `scripts/` 内，没有独立 `tests/` 目录。             | `skills/<slug>/scripts/`、`skills/<slug>/references/`、`skills/<slug>/assets/`、`skills/<slug>/agents/` |
| `evals/`                                        | 技能源文件   | 技能的行为用例与触发用例。                                                                                                   | `skills/<slug>/evals/evals.json`、`skills/<slug>/evals/trigger-eval.json`                               |
| 技能分组                                        | 数据约定     | 34 个公开技能分成 7 个 Scenario Group：delegate、review、git、tools、frontend、docs、create。                                | `apps/web/content/skill-catalog.yaml`                                                                   |
| `skill-catalog.yaml`                            | 配置文件     | 保存站点分组顺序、精选技能和每个技能的双语展示文案。                                                                         | `apps/web/content/skill-catalog.yaml`                                                                   |
| `skill-schema.ts`                               | 库           | 定义索引与 catalog 的 zod schema 和 `findCatalogIssues`，校验脚本与索引脚本共用。                                            | `apps/web/src/lib/skill-schema.ts`                                                                      |
| `skills:validate`                               | 脚本         | 检查每个技能的 frontmatter 规则和 catalog 条目是否齐全，不写文件。                                                           | `scripts/validate-skills.mjs`                                                                           |
| `skills:index`                                  | 脚本         | 解析全部 `SKILL.md`、可选的 `showcase.yaml`、catalog 和 git 提交时间，生成站点索引。                                         | `scripts/generate-skills-index.mjs`                                                                     |
| 生成索引                                        | 生成文件     | 站点页面的技能数据输入：列表、详情、分组布局三份 JSON，不手改。                                                              | `apps/web/src/generated/`                                                                               |
| Catalog Site                                    | Web 应用     | Next.js 站点，提供首页、技能列表、技能详情（en/zh），以及 `/llms.txt`、`/api/skills.json`、`/skills/<slug>.md`。             | `apps/web/src/app/`、`apps/web/src/lib/skills.ts`                                                       |
| Host 安装配置                                   | 配置模块     | 定义三种 Host 的安装命令，页面、`/llms.txt` 和 JSON 接口都读它。                                                             | `apps/web/src/config/hosts.ts`                                                                          |
| `@adonis-skills/i18n`                           | workspace 包 | 提供语言列表和 Lingui 配置给站点。                                                                                           | `packages/i18n/src/`                                                                                    |
| `pnpm brand:sync`                               | 脚本         | 从 `BRAND_REPO` 指向的品牌仓复制设计 token 快照，生成站点 CSS 变量和根目录 `DESIGN.md`；`brand:check` 只核对不写入。         | `scripts/sync-brand-tokens.mjs`、`apps/web/src/styles/brand/`                                           |
| pre-commit 钩子                                 | 质量门       | 提交触及技能、catalog 或插画时，跑校验与索引，并要求生成索引已暂存；另跑 prettier 与 typecheck。                             | `package.json`（`simple-git-hooks`）、`scripts/precommit-skills.mjs`                                    |
| CI `quality`                                    | 质量门       | 在 PR 和 `main` 的 push 上跑校验、索引新鲜度、品牌与设计 token 检查、站点单测、脚本测试、i18n 编译、lint、typecheck、build。 | `.github/workflows/ci.yml`                                                                              |
| `privacy-scan`                                  | 质量门       | 每次 push 和 PR 用 gitleaks 扫密钥、本机路径、主机名和回环端口。                                                             | `.github/workflows/privacy-scan.yml`、`.gitleaks.toml`                                                  |
| `skills:eval-grade`                             | 脚本         | 拿已收集的运行输出对照 `evals.json` 的期望 Route 打分。                                                                      | `scripts/grade-skill-evals.mjs`                                                                         |
| plugin eval 套件生成                            | 脚本         | 把 `agent-dispatch` 的 `evals.json` 转成 `claude plugin eval` 用的用例目录。                                                 | `skills/agent-dispatch/evals/build_plugin_eval.py`、`evals/`                                            |
| `skills:install:local`                          | 脚本         | 把公开技能装进仓内镜像目录供本地运行测试，`--sync-llm` 时确保 `.claude/skills` 软链指向它。                                  | `scripts/install-local-skills.ts`、`.agents/skills/`                                                    |
| 内部技能                                        | 技能源文件   | 只服务本仓开发的技能，不进索引、不发布。                                                                                     | `.agents/skills/`                                                                                       |
| `marketplace.json`                              | 配置文件     | 把整个仓库声明为一个 Claude Code plugin，技能目录指向 `./skills/`。                                                          | `.claude-plugin/marketplace.json`                                                                       |
| GitHub `main`                                   | 外部服务     | 发布面：三种安装方式和站点源码链接都指向这个分支。                                                                           | `llms.txt`、`apps/web/src/lib/skills.ts`                                                                |
| Hosts                                           | 外部角色     | 安装并运行技能的 agent 产品：`skills` CLI 系（Codex、Cursor 等）、Claude Code、Hermes Agent。                                | `CONTEXT.md`、`apps/web/src/config/hosts.ts`                                                            |
| Visitor                                         | 外部角色     | 在站点上找技能、判断是否合用、复制安装命令。                                                                                 | `CONTEXT.md`                                                                                            |

## 关系

| 起点                   | 终点                                            | 动作                                                                      | 协议或数据                                                   |
| ---------------------- | ----------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Maintainer             | `pnpm skills:new`                               | 运行脚手架命令                                                            | CLI 参数或交互输入                                           |
| `pnpm skills:new`      | `SKILL.md`                                      | 生成技能目录并改写 `description`                                          | 文件写入                                                     |
| `pnpm skills:new`      | `skills:validate`                               | 脚手架完成后启动校验                                                      | `pnpm` 子进程                                                |
| `pnpm skills:new`      | `skills:index`                                  | 校验通过后启动索引生成                                                    | `pnpm` 子进程                                                |
| 私有源导出             | `SKILL.md`                                      | 覆盖写入受管技能的全部文件                                                | 文件写入，清单见 `.export-manifest.json`                     |
| `skills:validate`      | `SKILL.md`                                      | 读取并检查 frontmatter                                                    | 文件读取，YAML                                               |
| `skills:validate`      | `skill-catalog.yaml`                            | 读取并核对每个技能都有条目、插画存在                                      | 文件读取，YAML                                               |
| `skills:validate`      | `skill-schema.ts`                               | 导入 `findCatalogIssues`                                                  | ES module import                                             |
| `skills:index`         | `SKILL.md`                                      | 读取 frontmatter 并把正文切成章节                                         | 文件读取，Markdown                                           |
| `skills:index`         | `skill-catalog.yaml`                            | 读取分组、精选和展示文案                                                  | 文件读取，YAML                                               |
| `skills:index`         | 生成索引                                        | 写出三份 JSON                                                             | 文件写入，JSON                                               |
| Catalog Site           | 生成索引                                        | 构建时导入技能列表、详情和布局                                            | JSON import                                                  |
| Catalog Site           | `SKILL.md`                                      | 构建时读原文，输出 `/skills/<slug>.md`                                    | 文件读取，`text/markdown`                                    |
| Catalog Site           | Host 安装配置                                   | 读取各 Host 的安装命令并渲染                                              | TypeScript import                                            |
| Catalog Site           | `@adonis-skills/i18n`                           | 读取语言列表与 Lingui 配置                                                | workspace 依赖                                               |
| `pnpm brand:sync`      | Catalog Site                                    | 生成 `brand-tokens.css`、`theme-roles.css` 和 `DESIGN.md`                 | 文件写入，CSS 与 Markdown                                    |
| pre-commit 钩子        | `skills:validate`                               | 提交前启动校验，失败则拦下提交                                            | `pnpm` 子进程                                                |
| pre-commit 钩子        | `skills:index`                                  | 提交前重新生成索引，有未暂存差异则拦下提交                                | `pnpm` 子进程，`git diff`                                    |
| CI `quality`           | `skills:validate`                               | 在 runner 上运行校验                                                      | GitHub Actions step                                          |
| CI `quality`           | `skills:index`                                  | 重新生成索引并要求与已提交内容一致                                        | GitHub Actions step，`git diff --exit-code`                  |
| CI `quality`           | `pnpm brand:sync`                               | 以 `--check` 模式核对生成的 CSS 与快照一致                                | GitHub Actions step                                          |
| CI `quality`           | `scripts/`、`references/`、`assets/`、`agents/` | 运行 `test:scripts` 里列出的技能公开性与脚本用例                          | `node --test`                                                |
| CI `quality`           | Catalog Site                                    | 运行单测、i18n 编译、lint、typecheck、build                               | `pnpm`、`turbo`                                              |
| `privacy-scan`         | GitHub `main`                                   | 扫描推送和 PR 的完整历史                                                  | gitleaks，规则在 `.gitleaks.toml`                            |
| `skills:eval-grade`    | `evals/`                                        | 读取期望 Route 并与输出比对                                               | 文件读取，JSON                                               |
| plugin eval 套件生成   | `evals/`                                        | 读取 `evals.json` 并生成用例目录                                          | 文件读取与写入                                               |
| `skills:install:local` | `SKILL.md`                                      | 经 `npx skills add ./skills` 把技能装进镜像目录，再整目录补齐被过滤的文件 | 子进程与文件复制                                             |
| `skills:install:local` | 内部技能                                        | 把公开技能的运行副本写到同一目录                                          | 文件写入                                                     |
| Maintainer             | GitHub `main`                                   | 推送提交，即完成发布                                                      | `git push`                                                   |
| Visitor                | Catalog Site                                    | 浏览、搜索技能并复制安装命令                                              | HTTPS                                                        |
| Visitor                | Hosts                                           | 在 Host 里执行复制的安装命令                                              | Host 自带 CLI 或斜杠命令                                     |
| Hosts                  | GitHub `main`                                   | 拉取 `skills/<slug>/` 或整个仓库                                          | `npx skills add`、`/plugin marketplace add`、`hermes skills` |
| Hosts                  | `marketplace.json`                              | Claude Code 读取 plugin 清单定位技能目录                                  | JSON                                                         |
| Hosts                  | `SKILL.md`                                      | 运行时加载技能指令，再按需读 `scripts/` 与 `references/`                  | 文件读取                                                     |
